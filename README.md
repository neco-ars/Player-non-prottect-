# Music Player

Музыкальный плеер, который ищет песню **сразу на нескольких площадках** и помогает найти **версию без цензуры**.
Один поиск: Звук, SoundCloud, Audiomack, YouTube и твои собственные файлы. Все найденные версии
песни показаны на одной карточке с пометкой площадки и значком **E** для explicit.

Работает на **Android**, **Windows** и в **браузере** (в том числе на iPhone: «На экран „Домой“»).
Своего сервера с музыкой у проекта нет: приложение обращается к площадкам напрямую от имени аккаунтов пользователя,
музыка нигде не хранится и не раздаётся.

---

## Возможности

**Поиск и версии без цензуры**
- Поиск одним полем по всем подключённым площадкам; одинаковые песни объединяются в карточку.
- Фильтр «только explicit»; пометки `explicit`, `uncensored`, `dirty` в названиях тоже распознаются.
- **Предпочитать explicit** — по нажатию на песню играет версия с пометкой E, если она есть.
- **Поиск оригинала** — когда играет «чистая» версия, плеер в фоне ищет ту же песню без цензуры на других
  площадках и предлагает переключиться.
- Если трек на одной площадке не играет, плеер сам пробует ту же песню на другой.

**Плеер**
- Полноэкранный плеер, очередь, перемешивание, повтор (вся очередь / один трек).
- **Моя волна** — бесконечное радио по твоему вкусу: учитывает, что ты дослушиваешь, лайкаешь и пропускаешь,
  и подстраивается прямо во время прослушивания.
- **Радио** по треку и **радио исполнителя** — похожие исполнители и их песни.
- Плеер в шторке уведомлений и на экране блокировки с кнопками ⏮ ⏯ ⏭, кнопки гарнитуры.

**Медиатека**
- Плейлисты, «Любимое», история прослушиваний.
- **Вход через Google и синхронизация** между телефоном, ПК и браузером ([как включить](docs/SYNC.md)).
- **Мои файлы** — mp3 / flac / m4a / ogg / wav с устройства: теги и обложки читаются автоматически, играют офлайн.
- Главная: «Похоже на …» по любимым исполнителям, «Новое для тебя» — похожие исполнители, которых ты ещё
  не слушал, «Недавно слушал», «Из любимого».

**Откуда рекомендации.** Большие сервисы подбирают музыку по прослушиваниям миллионов людей. У нас таких
данных нет, поэтому «кто на кого похож» берётся из открытого API Deezer (без ключа и входа, только названия
песен — музыка из Deezer не играет), а твой вкус — из истории, лайков и пропусков. Найденная песня играет с
наших площадок: плеер ищет ту же запись той же длины, без ремиксов и минусовок.

## Площадки

| Площадка | Что нужно | Что доступно |
|---|---|---|
| Мои файлы | ничего | свои файлы, офлайн (кроме веб-версии) |
| Звук | вход в свой аккаунт (без него — только поиск и 30-секундные фрагменты) | полные треки; 320 кбит/с с подпиской. В веб-версии — только через свой прокси на сервере в России ([`proxy-vps/`](proxy-vps/README.md)) |
| SoundCloud | ничего | полные треки, кроме Go+ |
| Audiomack | ключи Data API (выдаёт Audiomack по запросу) | полные треки |
| YouTube | бесплатный ключ YouTube Data API | ролики через официальный плеер YouTube (без фона) |

Ключи и токены вводятся в **⚙ Настройках** и хранятся только на устройстве.

## Установка

**Android** — скачай `music_player-android.apk` из [Releases](../../releases), открой, разреши установку из этого источника.

**Windows** — скачай `music_player-windows.zip` из [Releases](../../releases), распакуй, запусти `music_player.exe`.

**iPhone и любой браузер** — открой веб-версию по ссылке из раздела *About* справа, в Safari нажми
«Поделиться → На экран „Домой“». В веб-версии нет «Моих файлов», а в фоне с заблокированным экраном
iOS иногда приостанавливает звук.

## Сборка из исходников

Нужны [Flutter](https://docs.flutter.dev/get-started/install) (stable) и, для Android, JDK 21.

```bash
flutter pub get
flutter test
flutter build apk --release        # Android
flutter build windows --release    # Windows (нужны Visual Studio Build Tools с C++)
flutter build web --release --dart-define=PROXY_URL=https://<твой-прокси>.workers.dev
```

Ключи и адреса для сборки — в `keys.json` (образец: `keys.example.json`):
`flutter build apk --release --dart-define-from-file=keys.json`. Синхронизация включается значениями
`SUPABASE_URL` и `SUPABASE_ANON_KEY` — см. [`docs/SYNC.md`](docs/SYNC.md).
### Прокси для веб-версии

Браузер не пускает сайт напрямую в API Звука, SoundCloud и Audiomack, поэтому веб-версия ходит к ним
через маленький прокси (то же для Звука) на бесплатном Cloudflare Workers. Он пропускает только запросы к этим сервисам и только
с адреса твоего сайта. Установка — в [`proxy/README.md`](proxy/README.md).
Звук запросы с серверов Cloudflare отклоняет — для него есть свой прокси на сервере:
[`proxy-vps/README.md`](proxy-vps/README.md). Приложениям для Android и Windows
прокси не нужен.

## Устройство проекта

```
lib/
  main.dart                       запуск, системный плеер (шторка, экран блокировки)
  models/track.dart               трек, группа версий, выбор версии без цензуры
  sources/                        площадки: local, zvuk, soundcloud, audiomack, youtube
  services/
    search_service.dart           параллельный поиск и объединение версий
    player_service.dart           очередь, радио, повтор, перемешивание, поиск оригинала
    audio_handler.dart            кнопки в шторке / на экране блокировки
    library.dart                  плейлисты, «Любимое», история
    recommendations.dart          главная, «Моя волна», радио
    taste.dart                    «граф вкусов»: похожие исполнители (открытый API Deezer)
    sync.dart                     вход через Google и синхронизация (Supabase)
  ui/                             экраны
proxy/                            прокси для веб-версии (Cloudflare Workers)
proxy-vps/                        прокси на своём сервере (для Звука в веб-версии)
supabase/schema.sql               таблица для синхронизации
docs/SYNC.md                      как включить вход через Google
```

Новая площадка — это класс-наследник `MusicSource` (`search`, `streamUrl`, по желанию `similar`),
добавленный в список в `services/app_services.dart`.

## Важно

- Проект подключает только площадки, где музыку легально выкладывают артисты и правообладатели.
  Пиратские сайты не поддерживаются, и пулл-реквесты с ними не принимаются.
- Контент защищённый DRM (например, зашифрованные потоки SoundCloud) не воспроизводится — для таких
  треков плеер ищет версию на другой площадке.
- Звук и SoundCloud подключены через их неофициальные API: если площадка что-то поменяет,
  источник может временно перестать работать.
- Проект не связан с перечисленными сервисами; названия площадок принадлежат их владельцам.
